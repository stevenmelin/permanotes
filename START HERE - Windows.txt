PERMANOTES ON WINDOWS - START HERE
==================================

INSTALL (the easy way - no building needed)
1. Go to https://github.com/stevenmelin/permanotes/releases
2. Under the newest release, click "PermaNotes-x.x.x-Windows-Setup.exe" to download it.
3. Double-click it. If Windows says "Windows protected your PC", click
   "More info" then "Run anyway" (the app isn't signed with a paid certificate).
4. Click through the installer. PermaNotes opens when it finishes.

FIRST TIME
- To sync with your Mac and iPhone: follow "SETUP SYNC.txt".
- To bring in your OneNote notes: see "IMPORTING FROM ONENOTE" in README.txt.

BUILDING IT YOURSELF (only if you ever want to - GitHub does this for you)
1. Install Node.js (LTS) from https://nodejs.org and Inno Setup 6 from https://jrsoftware.org/isdl.php
2. Open the "windows" folder and double-click "Build Windows App.bat".
3. Then double-click "Build Windows Installer.bat".
4. The installer appears in the "release" folder.
